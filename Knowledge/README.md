# База знаний

Положи сюда документы о своём бизнесе — Claude будет использовать их как контекст.

Что сюда добавить:
- Описание продуктов и услуг
- Прайс-листы
- Внутренние регламенты и инструкции
- Справочники по процессам
- Презентации компании
- Кейсы и отзывы клиентов
- Исследования рынка

Форматы: `.md` и `.txt` читаются как есть, `.pdf` — тоже. `.docx` Claude Code сам не открывает: попроси конвертировать в markdown, он сделает это сам, и в базе окажется текст, а не непрочитанный файл.

**Положить файл — половина дела.** Скажи: «изучи этот документ и разложи в базу знаний» — Claude разберёт его на короткие заметки и впишет каждую строкой в оглавление ниже. Оглавление модель читает первым и по нему находит нужное; сорокастраничный файл, лежащий сам по себе, она не откроет, пока не поймёт, что он про то самое.
