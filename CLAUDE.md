# Рабочее пространство компании

> Этот файл — главная инструкция. Claude Code читает его первым при каждом запуске.
> Чтобы заполнить контекст компании, скажите: «обогати контекст» или запустите `/обогатить-компанию`.

## Кто мы

- **Компания:** [название]
- **Чем занимаемся:** [одним предложением]
- **Площадки:** [где находимся]

Подробности — в `Контекст/Компания/`. Восемь файлов по направлениям. Читай их, прежде чем что-то предлагать.

## Как со мной работать

- Общение на русском, на «ты».
- Результат — в файл, краткое резюме — в чат. Длинный ответ в чате теряется.
- Большая задача — сначала план, потом работа.
- Перед изменением файла сначала прочитай его. Никогда не перезаписывай вслепую.
- Не создавай файлы «на будущее». Только то, что нужно сейчас.
- Не удаляй ничего без подтверждения.

## Что можно и чего нельзя класть в этот репозиторий

**Можно:** описания процессов, инструкции, скиллы, сведения о компании словами.

**Нельзя:** себестоимость, цены закупки, рецептуры и технологические карты, выгрузки учётных систем, персональные данные сотрудников и клиентов, договоры, банковские реквизиты.

Правило простое: **сюда — как у нас устроено, не сюда — сколько это стоит.**

Данные живут рядом с папкой на вашей машине. Модель их читает, но в общий репозиторий они не уезжают.

## Структура

```
Контекст/
  Компания/     — кто мы: восемь разделов по направлениям
  тон-общения.md — как мы разговариваем с клиентами
Проекты/        — результаты работы
База знаний/    — процессы, регламенты, справочники
Шаблоны/        — шаблоны документов с плейсхолдерами
Входящие/       — файлы на обработку: кинул → попросил разобрать
.claude/
  commands/     — команды: research, анализ, тексты
  skills/       — скиллы: описанная работа, которую можно переиспользовать
```

## Чем пользоваться

Скажите задачу словами — Claude сам подберёт подходящее. Если хотите вызвать явно:

| Что нужно | Команда |
|---|---|
| Заполнить контекст компании | `/обогатить-компанию` |
| Разобрать планёрку | `/разбор-встречи` |
| Собрать документ по шаблону | `/создать-документ` |
| Разложить документ в базу знаний | `/база-знаний` |
| Разобрать компанию вопросами | `/мини-стратсессия` |
| Разобрать документ | `/analyze-document` |
| Исследовать компанию | `/prospect-research` |
| Проверить идею | `/idea-quickcheck` |
| Анализ по светофору | `/svetofor` |

Полный список — в `.claude/commands/` и `.claude/skills/`. Файлы читаемые, откройте любой.
